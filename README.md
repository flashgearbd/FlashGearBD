# FLASH GEAR BD — Free Website

## What is included
- Mobile-first homepage
- Product catalog with search/category filter
- WhatsApp ordering buttons
- Warranty policy
- Delivery policy
- Contact page
- Basic SEO metadata, robots.txt and sitemap.xml
- No database, paid hosting, or paid website builder required

## Before publishing
1. Open `assets/app.js`.
2. Replace `8801XXXXXXXXX` with the FLASH GEAR BD WhatsApp number in international format, with no `+` or spaces.
3. Confirm Facebook and Instagram URLs.
4. Replace the sample products/prices with your real catalog.
5. Change the canonical/sitemap URL if your Pages project name is not `flashgearbd`.

## Cloudflare Pages
Recommended setup for phone-only management: create a GitHub repository and connect it to Cloudflare Pages. Cloudflare will redeploy when you update the repository.

Alternative: Cloudflare Pages Direct Upload can upload a ZIP/folder from the dashboard, but a Direct Upload project cannot later be switched to Git integration.

## Important
The site is intentionally static. Product data is stored in `assets/app.js`, making small catalog edits possible without a database. For a larger store later, migrate the catalog to a proper CMS/database.
